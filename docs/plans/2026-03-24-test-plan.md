# Test Plan v2

Comprehensive test plan for the Oktopus project. Tests are designed to run locally via Docker without external devices. Each test either verifies a known bug (will fail, then code is fixed) or locks down existing behavior as a safety net for refactoring.

---

## Test Infrastructure

### Backend (Go)

All Go tests run inside Docker using the controller's existing build image (`golang:1.23`). A `docker-compose.test.yaml` provides MongoDB and NATS as test dependencies.

**New direct dependencies to add to controller `go.mod`:**
- `github.com/stretchr/testify` (upgrade from indirect to direct) -- assertions
- `github.com/nats-io/nats-server/v2` -- embedded NATS server for bridge/campaign tests
- No mocking framework -- use interfaces + manual test doubles

**Test docker-compose (`deploy/compose/docker-compose.test.yaml`):**
```yaml
services:
  mongo_test:
    image: mongo:7
    ports: ["27018:27017"]
    tmpfs: /data/db          # fast, ephemeral
  nats_test:
    image: nats:2.10
    command: ["--js"]        # JetStream enabled
    ports: ["4223:4222"]
```

**Run all backend tests:**
```bash
sg docker -c "cd deploy/compose && \
  docker compose -f docker-compose.test.yaml up -d && \
  docker compose -f docker-compose.yaml -f docker-compose.dev.yaml \
    run --rm -e MONGO_URI=mongodb://mongo_test:27018 \
    -e NATS_URL=nats://nats_test:4222 \
    controller go test -race -count=1 ./..."
```

Alternatively, a dedicated test Dockerfile that runs `go test` on build.

### Frontend (JS)

Tests run inside the frontend Docker container. Add to `package.json`:
```json
"devDependencies": {
  "jest": "^29.7.0",
  "@testing-library/react": "^14.0.0",
  "@testing-library/jest-dom": "^6.0.0",
  "jest-environment-jsdom": "^29.7.0"
}
```

Add `jest.config.js`:
```js
module.exports = {
  testEnvironment: 'jsdom',
  moduleNameMapper: { '^src/(.*)$': '<rootDir>/src/$1' },
  setupFilesAfterSetup: ['@testing-library/jest-dom'],
};
```

**Run frontend tests:**
```bash
sg docker -c "docker compose -f docker-compose.yaml -f docker-compose.dev.yaml \
  run --rm frontend npm test"
```

### Infrastructure

Config validation tests are written in Go (parse YAML/Dockerfile as text). They run without Docker dependencies -- just `go test` against the files on disk.

File: `deploy/tests/infra_test.go` (standalone Go module)
