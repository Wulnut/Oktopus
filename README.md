# Oktopus

Oktopus is an Open Source USP Controller and CWMP compatible multi-vendor management platform for CPEs and IoTs.

**Original Project:** [https://github.com/OktopUSP/oktopus](https://github.com/OktopUSP/oktopus)

## Usage

### Start Services

**Production:**
```bash
cd deploy/compose
./run.sh
```

**Development (doesn't require restart after frontend modified):**
```bash
cd deploy/compose
./run_debug.sh
```

### Stop Services

```bash
cd deploy/compose
./stop.sh
```

### Certificates

Registry certificates are automatically generated by the `registry-certs-generator` service. Certificates are stored in the `registry-certs` Docker volume and include all host IP addresses. Certificates are regenerated automatically if host IPs change.

## Modifications

### Containers & Registry

- **Docker Registry**: Integrated into compose with automated certificate generation
- **Container Management**: Added UI for uploading, managing, and deploying containers
- **Update System**: Container update functionality with tag selection and version checking
- **Registry Integration**: Frontend connects to local registry via nginx proxy at `127.0.0.1:443`
